# 区域圆角与视觉统一实施任务

> v1.0 · 2026-10-12 · 依据 [spec.md](spec.md)。RV-T00～RV-T08 的实现代码已推进并完成 Windows 目标构建；`[~]` 仅表示真实窗口截图/交互证据尚未闭环，未因编译通过自动签收。
> `RV-` 是本轮前缀，不重编号旧 T-xxx。证据写入 [acceptance.md](acceptance.md)。

## 1. 执行规则

`[ ]` 待做、`[~]` 进行中、`[x]` 完成且验证、`[!]` 阻塞。开工登记实际负责人和工作区快照；不要求清空已有改动，不用 stash/reset/clean。用户此前已授权继续 GUI 工作，不重复请求常规修改许可。

各任务允许范围只覆盖 UI 部分；同名文件内业务函数仍受 RV-027 保护。确需扩大范围，先在本文记录原因和边界。依赖按下表满足后实施；允许独立文件分别推进，但本文不要求启动子代理。GUI 夹具串行运行，产品与同目标构建串行。

每任务完成需给出：实际修改范围、关联规范 ID、构建/检查结果、同场景截图、已知偏差及回退补丁/快照。未执行不能标 PASS，历史日志不能作为新改动后的验证。
