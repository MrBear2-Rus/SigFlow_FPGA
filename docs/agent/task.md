# 教育 Agent GUI 执行清单

> 版本：v1.0 · 2026-10-09。依据：[Agent GUI spec v1.1](SigFlow-Edu-Agent-GUI-Spec.md)。  
> 本清单全部待实施，不沿用其他 spec/task 的历史完成勾选。共享基础：[主窗口 task](../gui/task.md)。

## 1. 使用和责任规则

状态：`[ ]` 待做、`[~]` 进行中、`[x]` 完成并归档证据、`[!]` 阻塞。每项完成回填实际负责人、commit/工作区标识、契约版本、构建/测试命令、PASS/FAIL/SKIP 与手工截图/演示。Mock、真实 sidecar、模型、工具和设备证据分别登记。

建议责任：S1（客户端/协议/可信控制器）、S2（工程/波形/报告/调试适配）、S3（面板/交互/集成），U1/U2/U3（Agent 运行时/策略/课程与学习记录）。角色沿用 edu-agent 文档，开工时映射到实际成员，不代表已分配人员或获准启动并行 agent。

UI 单项可在 Mock 中开发，但依赖未完成时标“组件已验证、真实接入阻塞”，不得把对应业务功能勾选完成。未知动作不能直接向 v1 服务提交；跨组接口变更同步 schema/OpenAPI/fixture/CHANGELOG。
