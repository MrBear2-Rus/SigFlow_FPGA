# Edu Agent 内容浏览实施任务

依据 [增量设计](edu-agent-reading-design.md) 和 [原 Agent GUI 任务](task.md)。目标是让当前已加载的对话、学习路径及教学辅助内容可完整浏览。首批任务限定在 C++ 原生 GUI，沿用现有 Windows CMake、wxWidgets 和正式宿主测试入口。

实施记录见 [原生交互验证](edu-agent-reading-verification.md)。下方清单保留完整窗口签收项，自动化验证结果按该记录核对。

| 批次 | 顺序 | 交付条件 |
| --- | --- | --- |
| 一 | READ-01 → READ-02 → READ-03 → READ-04 | 展开后可以滚到末行，侧栏可以重复定位，鼠标和键盘滚动均可操作，Windows 原生验收通过。 |
| 二 | READ-05 → READ-06 | 窄窗口和高 DPI 下可达全部内容和操作按钮，长文本有明确阅读或复制入口。 |
| 独立增量 | READ-07 | 有经过确认的向前分页契约，旧页只合入原绑定运行，并保持当前阅读位置。 |

## READ-01 记录原生窗口基线

核查入口为 `main/agent/gui/AgentWorkspace.cpp`、`AgentConversation.cpp` 和 `AgentControls.cpp`。

- [ ] 从仓库根执行 `cmake --build build-main-msvcrt --target sigflow --parallel 6`。记录提交、构建配置、wxWidgets 版本、Windows 显示缩放和窗口形态。
- [ ] 打开 `examples/full_adder` 的 `sigflow.project`，从 Agent 工作台记录基线。在测试数据中加入有识别标记的长中文末行、长代码行和多个展开的辅助章节。数据来自正式宿主测试模式或受控界面夹具，并记录数据来源。
- [ ] 记录三种操作前后的视口高度、虚拟高度和纵向滚动位置。直接展开辅助分区后拖到底，页面滚动后重复点击侧栏，鼠标停在只读对话正文上滚轮。另验证短浮窗中学习路径是否仍有正的滚动视口。

完成条件是每个现象都有能复现的步骤或明确标记为未复现。先记录故障证据，再写修复。

## READ-02 统一展开和跳转后的布局更新

修改 `main/agent/gui/AgentWorkspace.cpp` 和 `AgentWorkspace.h`。沿用 `AgentAccordion` 已有事件。

- [ ] 为教学辅助折叠事件接线。把直接点击、侧栏展开和正文刷新接入同一测量路径。在投影和子控件尺寸就绪后设置外层虚拟高度，再恢复或调整滚动位置。
- [ ] 调整 `ArrangeSupport`，在竖滚动条改变视口宽度时重新按新宽度换行。使用当前可见分区底边确定垂直范围，收起后校正滑块位置。
- [ ] 让 `ScrollPageTo` 接收目标控件或目标矩形，先映射到滚动窗口客户坐标，再转换成虚拟坐标。已可见时保留位置。定位辅助标题时使用辅助区自己的坐标和滚动单位。
- [ ] 验证先直接展开尾部分区再拖到底可以看到末行标记。收起后不能拖到空白尾部。分别从页首、页中和页尾点击同一个侧栏入口，确认目标标题每次都完整可见。

## READ-03 修复滚动输入和阅读位置

修改 `main/agent/gui/AgentWorkspace.cpp`、`AgentConversation.cpp` 及相应头文件。复用现有消息锚点与形态切换时的滚动状态。

- [ ] 按 READ-01 记录修复能吞掉竖滚轮的原生控件。在 Agent 边界内按鼠标位置决定滚动区，内层到边界后交给外层，处理高精度滚轮累积和每次输入只移动一个滚动区。保留水平滚动和正文选择行为。
- [ ] 让正文获得焦点时 Page Up、Page Down、Home、End 可浏览该区。输入框聚焦时保留编辑键。测试滚轮悬停的位置与键盘焦点不同时，各自作用于预期区域。
- [ ] 验证对话追加时，读到末尾才跟随新消息。验证在旧消息中间、已经打开的教学分区中间、浮窗切回工作台时，首个可见项及其相对位置可恢复。切换工程、修订和运行后核对旧位置不会带到新内容。

## READ-04 验收第一批原生交互

- [ ] 构建 `sigflow` 和 `edu_u2_gateway`。在中央工作台和浮窗中，用正文、标题、按钮边缘、空白区四类位置分别验证滚轮。用实际鼠标按住滑块拖到两端，确认可见首项和末行标记。
- [ ] 把长对话、课程引用、学习记录、检查器、证据链和学习路径各测一遍。验证竖向滚动、横向宽代码以及长文本选择复制。加载过程中再展开分区，确认新高度在加载完成后生效。
- [ ] 用全加器工程运行仿真后从正式 Agent 工作台开始规则教学，查看证据、生成下一提示并结束，在记录返回后滚动到底。记录宿主数据成功但 GUI 操作失败的场景。
- [ ] 保存基线与修复后的结果、截图或操作记录，按场景登记 PASS、FAIL、SKIP 及理由。通过后签收第一批，未通过项附复现路径和修改点。

## READ-05 窄窗和高 DPI 重排

修改 `ArrangeGuide`、`ArrangeConversation` 和 `AgentConversation::MeasureText`。仅在现有入口不足时调整相关布局策略。

- [ ] 当固定尾注使路径视口不足一个步骤时，将尾注加入路径的虚拟高度，保证步骤和尾注均可随内容滚动。恢复宽幅时还原固定尾注并保留可见步骤。
- [ ] 按实际字体、内容宽度和控件内边距计算正文高度。测试长中文、长标识、长链接、末尾换行及宽表格。验证缩放后仍能看到输入、发送和教学动作。
- [ ] 在 Windows 以约 375、560、960 DIP 及较宽窗口测试布局。在 100%、125%、150% 缩放下至少各跑一次窄窗用例。验证屏幕缩放变化、对话追加和展开新分区后，滚动范围及阅读锚点仍正确。

## READ-06 查看全文与限量提示

使用 `main/agent/gui/AgentSupport.cpp` 和 `AgentNavigation.cpp` 的现有投影，入口放在对应分区。

- [ ] 对尚有正文但标题或摘要被省略的证据、课程或学习记录，提供「查看全文」或「复制」。详情支持选择、滚动、Esc 关闭和恢复焦点。复制后的内容与已投影文本一致。
- [ ] 对宿主标记限量的数据说明当前范围。详情跟随工程、修订和运行绑定切换，切换后核对旧详情已关闭。
- [ ] 验证很长的标题和正文能完整读取或复制。当前运行只返回最近记录时，用户可以分辨内容限量和窗口截断。

## READ-07 查看较早教学时间线

前置为 READ-02 和宿主接口协作确认。涉及 `teaching_routes.py`、`teaching.py`、宿主 `store.py` 及原生 `AgentApiClient` 和证据链投影。

- [ ] 固化可选 `before` 参数的合法范围以及保留窗口内无更多、过期和无效游标行为。测试省略游标及已有 `after` 请求保持兼容，`before` 与 `after` 同时提供时拒绝。
- [ ] 实现向前查询，验证不少于 30 条事件的连续分页顺序、边界无重复、首尾恰好填满和较旧数据已淘汰的情况。同步接口说明与变更记录。
- [ ] 在「证据链」追加「加载较早记录」。后台合入前校验当前绑定和版本。在真实宿主验收中反复加载、遇到过期和请求中切换工程，确认无重复、无旧数据串入且原可见条目仍在原位置。

每个任务验收后记录构建版本、Windows 缩放、工作台形态、数据来源及验证结果。自动化布局断言和正式宿主回归分别提供证据，原生滚轮和滑块拖动以实际窗口结果为准。
