# K2 接口与首轮实现

日期：2026-11-13。前置门槛：K1/G1/A2/A3 已凭生产 C++ 和真实工具测试通过。**K2 目前为首轮实现，未关闭完整 K2 或其它 M0 门槛。**

## 公共边界与所有权

| 接口 / 文件 | 当前合同 | 复用边界 |
|---|---|---|
| `VirtualSession.h/.cpp` | 一个持续 worker；构造、写输入、eval、读取输出、final、销毁模型均在该线程 | 无 wx；GUI/后续 IPC 只能 Submit 请求 |
| `IDutAdapter` | WriteInput(PortBitRef,bool)、Evaluate(EventPosition)、ReadOutput(PortBitRef)、Finalize | Verilated 成员访问的明确适配器；不按信号名猜物理连线 |
| `SessionContract` | 完整 manifest、CST-derived bindings、电气 profile/身份、物理输入端点、clock、配额和指纹 | 模型工厂前验证声明覆盖和电气条件；不合格不创建 DUT |
| `InputEndpoint` | target→package_pad、固定 driver 集、显式初始 manual 状态 | 通过 CST pad_map 找到 PortBitRef；alias 不能绕过 CST 直达端口 |
| `EventPosition` | tick:u64、delta:u32、event_seq:u64；JSON tick/seq 为十进制字符串 | 1ps 整数时间；同 tick 多次 eval 的 delta/seq 不合并 |
| `logic_state.hpp` / `Resolver.cpp` | 固定 `sigflow.state-m0.v1`；保留 12 个基础态名及 CON flag 的产品表达 | 当前解析 F/W/S 子集；I/P 明确 unsupported，不声称完整 Proteus 矩阵 |
| `ReplayCommitted` | 新 worker 从零创建新模型；校验指纹后只回放 commit 中实际输入，并逐次对照输出 | 不重新计算暂停意图合并，不回放 superseded/cancelled 请求 |

当前参考适配器位于 `tests/virtual/k2/verilated_runner.cpp`，明确对应 `k2_counter` 的实际 Verilated C++ 成员；通用适配器生成器与 `eda-sim-verilator` Job 生命周期装配仍待后续 K2。它不是把 K0 spike 改名：命令、线程、clock、guard、journal 和 replay 均调用 `core/src/eda-virtual-board/` 的生产实现。

## 状态与命令

| 状态 / 命令 | 行为 | 返回或转移 |
|---|---|---|
| 构造完成 | 完整输入预检后进行初始化 eval；若有未知输入则一位也不写 | Paused(reason=Ready)，或 Paused(reason=UnknownInput) |
| Paused / set | 仅校验并暂存意图；每目标最后意图生效 | pending；被替换者 superseded，并记录 by |
| step | 提交暂存的非时钟输入并 eval，再推进恰好到下一上升沿 | Paused(StepComplete)，或 blocked/UnknownInput |
| play | 先提交暂存输入，再在安全边界推进时钟 | Running；配额用尽转 Paused(ResourceLimit) |
| Running / set | 队列顺序接收，在下一个安全边界预检、提交 | applied 或 blocked；之后的 Pause 不越过此前输入 |
| pause | 当前事务完成后 ACK | Paused(User)，ACK 后时钟、输入写入与 eval 冻结 |
| stop | pending→cancelled；final 一次，模型在 worker 销毁 | Stopped；重发相同 Stop id 返回原 ACK |
| 相同 command_id | 同内容返回已知处理状态；不会再次施加 | 内容不同返回 E_COMMAND_ID_REUSED |
| 适配器异常 | 停止模型处理并结束队列；不继续制造 applied ACK | Faulted / rejected；退出时补齐一次 final 尝试 |

协议入口为 `Submit(Json)`，可直接映射 JSONL；get/journal 返回只读快照，set/step/play/pause/stop 必须带 command_id。`__session_` 前缀保留给内部收尾。队列、命令和 commit 数均有硬配额；尚未接入 GUI 的异步 job/会话控制按钮。

```json
{"op":"set","command_id":"press-1","target":"key_p3","state":13}
{"op":"step","command_id":"step-1"}
{"op":"get"}
```

state=13 为 SLO，release 使用 FLT(2)，由按键端点保留的外部 WHI 上拉决定最终高电平。clock 的输入所有权单独保留，不允许普通 set 接管。

## STATE 与导入 guard

| 条件 | 本轮实际规则 | DUT 输入写入 |
|---|---|---|
| 无驱动 | FLT | 拦截，Paused.UnknownInput |
| WHI 与 SLO 同网 | SLO 胜出 | 0 |
| 同级强高、强低 | SUD 基础码 + CON(0x20) | 拦截 |
| UND / WUD / SUD / CON | 未知，不先转换 bool | 拦截 |
| 仅 WHI | 有效高 | 1 |
| 输出支路 FLT | GuardInput 返回 ObserveOnly | 不反向写 DUT，不由该 guard 暂停 |
| I/P 或非法编码 | E_STATE_UNSUPPORTED / E_STATE_INVALID | 拒绝进入解析支持子集 |

Driver 按稳定 driver_id 排序，重复 ID 被拒绝。M0 直接对完整 DriverSet 选取最高受支持强度，避免把低强度中间冲突错误折叠成最终 CON；这不是已验证的完整 32×32 折叠表，不能据此宣布结合律成立。UND 和带 CON 的来源采取保守未知策略。

每次 Evaluate 之前先 resolve 并预检**全部**输入，包括初始化、组合输入和异步复位。任何未知值都会记录 port ref、Pad、原始 STATE、driver 列表、attempted_position 与 last_committed_position，保持待提交意图；本事务没有任何输入写入、eval 或正常 commit。修复仍先暂存，Step/Play 再尝试。

当前时钟是固定频率、1ps tick 的整数余数累计；27MHz 第一上升沿为 18519ps。只支持无内部 `--timing` 事件的参考 RTL；脉冲调度、多个时钟、外围时间轮、delta 反馈调度和 `E_NON_CONVERGENT` 完整处理尚待后续，不把现有 eval 调用包装成全事件内核。

## journal 与重放

| 记录 | 内容 | 恢复语义 |
|---|---|---|
| run_header | source、adapter binary、电气文件、CST binding 摘要、resolver、tick、clock 指纹 | 任一不同，拒绝重放 |
| intent / decision | pending、superseded、cancelled、blocked 的请求与原因 | 只供审计，不重新施加 |
| commit | 精确 position、全部实际有效输入、输出快照、batch_id | 从零电气重放的唯一输入事务 |
| input_commit / control | 实际 applied 请求、Step/Play/Pause/Stop 边界 | 辅助追踪教学控制旅程 |

本轮 journal 是**有界内存记录**，所有 ACK/记录均声明 `durability=memory`。测试结束后导出的 JSON 是证据，不代表每个 ACK 已 fsync，也不代表 crash-safe 原子提交。落盘 commit marker、半批恢复、LiveTrace 共同提交和两类结果 digest 尚未实现，不关闭 G3。

| 验证入口 | 本轮范围 | 证据 |

复现：先完整构建 `build-m0`，再执行 `python tools/virtual/verify_k2.py`，或直接运行注册的 CTest。脚本会强制 runner 重新链接当前 Core 静态库，避免拿旧二进制验证新源码。

后续按依赖顺序继续：通用 Verilated adapter/进程握手与生命周期 → 持久 journal/恢复协议 → LiveTrace 不可变 read view → GUI 会话按钮/虚拟板 → 输出支路开路网络与故障面板。完整 K2 和 A4～A10 仍应逐项实测，不由本轮首个真实计数器通过而自动关闭。
