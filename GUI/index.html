液态玻璃工艺

严格按参考实现：45° 边缘高光渐变、白色内阴影压在暗色内环之上、柔和外投影、contrast() 对比滤镜、1px 双层低透明描边、内缩模糊光环。整套玻璃不依赖 backdrop-filter，因此同样可被 wxWidgets 自绘近似。

01

玻璃单元

圆形玻璃按钮与玻璃胶囊 CTA（含尾随深色箭头）
Glass

工艺拆解

  • 1边缘高光 linear-gradient(45deg, #fff 0%, transparent 25%, transparent 75%, #fff 100%)
  • 2白色内阴影（右上/左下）压在暗色内环 inset 0 0 2px rgba(0,0,0,.8) 之上
  • 3外投影 0 4px 8px rgba(0,0,0,.2)
  • 4双描边 border:1px double rgba(51,51,51,.08)
  • 5模糊光环：::before 内缩 16px、top:35%、blur(8px)；::after 内缩 4.5px、blur(1px)
  • 6对比滤镜：容器 filter: contrast(3)

规格
