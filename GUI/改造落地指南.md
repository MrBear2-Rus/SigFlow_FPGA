> 配套交付物：`app.html`（完整可交互原型，自定义布局全部实装）+ `index.html`（组件模块库 / 设计体系，模块 01–25）。
> 工程目标：`D:\sigflow2026project\SigFlow_FPGA`（wxWidgets 3.2.9 + C++，MinGW GCC）。
> 本指南回答一个问题：**如何把现有 wxWidgets 程序完整改造成原型里的这个界面**。

## 二、亮色主题数值（Token 层 → `UiTheme.h`）

浅色档按 Apple 设计规范取值；`UiTheme.h` 里同名常量更新为：

| Token | 浅色值 | 用途 |
| --- | --- | --- |
| `--hue-bg-1` | `#fbfbfd` | 页面/窗体底（近白过渡层） |
| `--hue-bg-2` | `#f5f5f7` | 苹果灰（钻石级主面） |
| `--hue-bg-3` | `#e8e8ed` | 行间最深一档 |
| `--surface` | `rgba(245,245,247,.66)` | 磨砂面（工具栏/HUD 用） |
| `--surface-strong` | `rgba(255,255,255,.86)` | 面板本体（含弹层） |
| `--surface-sunken` | `rgba(29,29,31,.045)` | 输入框凹陷底 |
| `--text-1` | `#1d1d1f` | 正文墨（Near-Black Ink） |
| `--text-2` / `--text-3` | `#565a66` / `#878c99` | 次级/辅助文字 |
| `--stroke` / `--stroke-strong` | `rgba(18,24,40,.10)` / `.18` | 描边两档 |
| `--accent` | `#0071e3` | Apple 行动蓝（选中/焦点/链接） |
| `--brand` | `#1f8a4c` | 品牌绿（仅 Synthesize 主 CTA 与品牌标识） |
| `--warn` / `--danger` | `#b25000` / `#c1121f` | Program 键 / 关闭键 |
| 圆角 | 6 / 9 / 13 / 18 / 24px（`--r-xs…xl`） | 控件→窗口 |
| 阴影 | `--shadow-1` 柔影 / `--shadow-2` 大面影 | 普通阴影，无立体玻璃层 |
| 动效 | `--t-press:140ms --t-quick:180ms --t-panel:260ms`；ease-out 进 | |

材质规则（全站三条）：
1. **结构面**（外壳/侧栏/底栏/弹层）= 半透明底 + 柔和 blur 近似 + 1px 描边 + 普通软阴影 + 顶部 1px 高光；不做 45° 高光、double 描边、暗环。
2. **按键** = 平面半透明或纯文字，hover 才有淡底；不做立体玻璃。
3. **唯一例外**：工具栏 Synthesize 主 CTA 保留"亮色系液态玻璃模块"七层工艺（见 index.html 模块 01 `.lg-glass` 配方表，wx 侧按层序自绘近似）。

## 三、各区域自绘方案（P1 重点）

### 1. 标题栏（38px，Windows 原生三键）
- 去系统标题栏：`wxAuiToolBar`? 否 —— 用无边框窗口 `wxTopLevelWindow::ShowWithoutActivating`? 实操：`wxFrame` 设 `style=wxNO_BORDER` + 自绘一条标题栏面板。
- 品牌绿渐变小方牌 + 波形 SVG（自绘 `wxGraphicsContext`）+ 工程路径 + `● 未保存`（`--warn` 色）。
- 右上依次：布局开关簇（三个 28×26 图标键 + 一个「自定义布局」键）→ 最小化/最大化/关闭（46px 宽全高，close hover 用 `--danger`）。
- Windows 最大化/关闭的实际窗口操作走 `WM_NCHITTEST` / `SendMessage(WM_SYSCOMMAND)` 自实现点击区。

### 2. 菜单栏（32px）
- 高度 32px，顶层条目**纯文字**：无边框、无底色、无按压缩放；hover 只加深文字（`--text-1`）。
- **仅在展开时高亮**：浅色 `--sel`（≈ 蓝 11% 透明度）+ 蓝 `--accent` 文字；点程序内其他位置收起即取消高亮。
- 落地：自绘 `wxAuiToolBar` 或自绘菜单栏；下拉浮层 = `wxPanel` 自绘：`--surface-strong` 底 + 1px 描边 + `--shadow-2` 软影 + 圆角 13px；项 hover `--sel` 底 + `--accent` 字；快捷键右对齐 tabular-nums。
- 快捷键与 `MainMenuBar.cpp` 逐项一致（红线 5）。

### 3. 工具栏（48px）
- 顺序：`Synthesize ⌘R`（液态玻璃主 CTA）→ `Place & Route`、`Program(PnR warn 橙描边)` → 分隔线 → `Simulate`、`Waveform` → 弹性空间 → `PnR 运行中 mm:ss` 状态 chip → `组件库`、主题切换。
- chip 规格径：高 30px、胶囊圆角、1px 描边（`--stroke`）、半透明白底；hover 提一档底色；按压 scale(.97) 140ms。
- Synthesize CTA 层序（自绘近似，由外到内）：外投影 `rgba(0,0,0,.20) 4px/8px` → 暗内环 1px → 右上/左下白高光压在暗环上 → 次级白内影 → double 弱描边 `rgba(51,51,51,.08)` → 内缩 4.5px 白光环 → 中心 35% 内缩 16px 模糊暗环（真机无模糊则跳过并用加深暗环补偿）。

### 4. 活动栏 + 三页互斥侧栏（左栏，可被「主侧栏」布局控制）
- 活动栏 46px 宽竖条：三个 34×34 图标键（Project / SigFlow Tree / Component Library），选中 = `--sel` 底 + `--accent` 图标 + 左侧 3px 指示条；底部竖排 PANELS 小字。
- 轨道宽度可拖拽（210–460px），把手 hover/拖拽变 `--accent`，宽度持久化。

### 5. 中部：画布 + 代码编辑器（上下可拖分栏）
- 分栏默认 62% / 38%，拖拽范围 25%–80%，把手 44×3。
- 画布：白底 + 20px 细网格 + 100px 粗网格；元件=圆角卡 + 名称/实例号；手柄 7×7 蓝方块；导线 2px 正交圆角 + 3.6px 结点；幽灵放置（品牌绿虚线 62%）；顶部浮动工具条（圆玻璃改普通磨砂胶囊）与左下缩放 HUD。
- 代码区：标题 `top.v — Verilog · Tree-sitter 已校验` +「拖出」键（见 §五）；SF Mono 12.5px 主导视觉。

### 6. 辅助侧边栏（**永远最右侧**；可拖 230–520px）
- 三页：Property（表单行）、Pin Binding（封装+IOB 绑定）、DeepSeek（Agent Chat）。
- 表单：label 11px 次级灰 + 输入框 11.5px（凹陷底 1px 描边、focus 蓝描边+3px 光环）。

### 7. 底部面板 + 状态栏
- 底部（面板）：Terminal（等宽 11.5px，`$ command` 蓝、`[Ready] eda-…` 绿、`[WARN]` 黄黄 note）/ Waveform（SF Mono 信号名右对齐 + 34px 波形 SVG 行高 32）。
- 状态栏（可整条隐藏）：10.5px，左：状态灯+当前操作；右：坐标 / Grid 20 / Zoom / 工具链版本。

### 8. 字重再平衡（"电路图与代码主导"）
- 降档类目：元件库树 11.5px、分组头 9.5px/600 拉开字距、徽章 9.5px、表单 label 11px/500 次级灰、Terminal 11.5px、状态栏 10.5px、标签 11.5px/530。
- 保持不变：画布元件文字（13px 主导色）、代码区 12.5px、Synthesize chip 12.5px。

## 四、自定义布局引擎（P3 重点，对齐 VS Code + 原型）

### 1. 状态模型
```cpp
struct LayoutState {
  bool   menuBar, rail, left, right, bottom, statusBar; // 六栏显隐
  Side   side;    // 主侧栏位置: Left / Right
  Align  bal;     // 底部面板对齐: Left / Right / Center / Justify
  bool   panelTop;// 面板位置: 底部(false) / 顶部(true)
};
// 持久化: wxFileConfig("sigflow-layout") 或 JSON；键名与原型 localStorage(sigflow-layout-v2) 对应
```

### 2. Quick Pick「自定义布局」面板
- 入口：标题栏右上布局簇第 4 键（aria-expanded）。
- 结构（340px 宽，与参考图一致）：
  - 标题行（含 Esc 关闭）；
  - 布局预设 chips：经典 / 编码优先 / 画布优先 / Chat 分离 —— 与当前状态实时比对，全命中才亮；
  - 可见性组：菜单栏 Ctrl+Shift+M / 活动栏 Ctrl+Shift+A / 主侧栏 Ctrl+B / 辅助侧边栏 Ctrl+Alt+B / 面板 Ctrl+J / 状态栏 —— 隐藏项整行转灰；
  - 主侧栏位置：左对齐 ✓ / 右对齐（**辅助侧边栏始终最右**，主侧栏右对齐时只需移到画布右侧邻位）；
  - 面板对齐方式：左 / 右 / 居中 / 两端对齐；面板位置：底部 ✓ / 顶部对齐；
  - 工作区拖出组：绘图窗口 / 代码编辑窗口 / Agent Chat → 独立窗口。
- 全部行可键盘走（Tab + 方向），当前组打勾用 `--accent`，选中态底色 `--sel`（同时有图标/文字佐证，不裸靠颜色）。

### 3. 快捷键（wxAcceleratorTable / 全局 hook）
Ctrl+B（主侧栏）· Ctrl+Alt+B（辅助侧）· Ctrl+J（面板）· Ctrl+Shift+M（菜单栏）· Ctrl+Shift+A（活动栏）。Esc 关面板/菜单。

### 4. 独立工作窗口（多显示器）
- 绘图 / 代码编辑 / Agent Chat 三区各挂「拖出」按钮（编辑区标题右端、画布右上角、Chat 页签栏右端）。
- 落地：`wxFrame`（无标题栏轻壳或保留原生框二选一，默认轻壳）内嵌 `wxPanel` 迁移；或先做 **AUI 浮动 pane**（`wxAuiManager` + `wxAUIClient` 浮动持提升为独立顶层窗口）。
- 多显示器：`wxDisplay::GetCount()`；拖出时默认 `wxDisplay::FromPoint(mouse)` 放置；窗口关闭即回归 主窗口占位（原型里显示"已拖出 —— 回归主窗口"按钮）。
- 占位态：对应区域显示中央提示 + 回归按钮；快捷状态栏提示 `已拖出：code-editor`。

### 5. 对齐方式实现要点
- 主工作区由 grid 改 **flex 轨道**：rail(order0) → 主侧栏(order1) → 中区(order2) → 辅助侧边栏(order3)；右对齐仅改 order（2↔3 类的映射见 `app.html` 末尾样式段）。
- 底部面板对齐：左 = `minmax(420px,760px) 1fr`；右 = `1fr minmax(...)`；居中 = `width:min(840px,88%);margin:auto`；两端 = 默认 1fr。
- 面板位置顶部：窗口行序 order 交换（bottomwrap ↔ workspace）。
- 窄屏（<1024）兜底：两 dock 用 clamp 宽度；<760 隐藏辅助侧边栏、工具条横向滚动，无横向滚动条。

## 五、动效规格

| 场景 | 数值 |
| --- | --- |
| 按压反馈 | `:active scale(.97)`（图标键 .94），140ms，指即时反馈不用 ease-in |
| 弹层进入 | rise：`translateY(6px→0)` + 淡入 180ms ease-out；退出 60–70% 时长 |
| 面板显隐 | 直接 display:none（原型保持即时），窗口级 materialize 260ms |
| 标签指示条 | 2px 品牌色条 `translateX` 滑移 260ms |
| 降动效 | `SPI_GETCLIENTAREAANIMATION==0` 时关闭位移动画 |

## 六、红线核对（改造后自查）

1. 信息架构不变：左三页互斥 + 中区布局/编辑 + 右栏/底栏可拖 + Terminal/Waveform + 状态栏。
2. 全部快捷键保留；Terminal 的 `[Ready] eda-…` 插件诊断可见。
3. 颜色零硬编码：一律 `UiTheme.h` token；新调节点只有 Synthesize 玻璃配方与字号微调档。
4. 深色档在 P2 完成前逻辑仍锁浅色（`kForceLight`）；P2 后深色取值独立校准。
5. 「自定义布局」不改命令语义 —— 菜单结构 / 工具链全保留。

## 七、风险与说明

- 浮动子窗口 + wxCanvas 的渲染上下文迁移是最大工程量点（需实测跨显示器 DPI）。
- 原型观感（blur/玻璃）强于 wx 自绘；落地以 token 与层级为准。
- 快速面板与 AUI 若冲突：**布局引擎管显隐/位次，AUI 只管拖拽**，别让两套状态打架。
