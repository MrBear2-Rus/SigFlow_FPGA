SigFlow FPGA Tools

工作区

综合（synth_gowin）

说明

调用本机 yosys；产物写入任务目录的 artifacts/。 未安装 Yosys 时任务会以失败结束，日志中给出工具错误。

布局布线（nextpnr）

可在左侧综合任务的产物上点“用作 nextpnr 网表”自动填入路径。

打包（gowin_pack）

仿真构建（Verilator）

简化解析器只提取时钟与部分激励，不支持完整 testbench 语义。

运行

构建成功后，在右侧任务产物上点“用作仿真程序”自动填入。 波形写入产物目录；波形查看等 C++ P7。

openFPGALoader

烧录（flash）尚未在 C++ 侧实现（P4 剩余项），本页先保留结构。 需要 Node 的设备租约与用户确认流程，等 C++ flash provider 落地后接入。
