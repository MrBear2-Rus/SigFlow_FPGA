# 阶段 25：连续同类问题的提示建议

日期：2026-10-20。基线：04648a9。对应 UA-06“连续三次同类真实错误只建议，不自动升级”。

## 行为

正式 U2 宿主从已经核验的 Evidence 投影 teaching_observation 元数据。只有 diagnose 意图、tool 来源及置信来源、有效锚点、完整证据且模式 assessment=supported 才可计数。中性 job_observation、fixture、假设、不完整证据和合法反例不计为真实错误。

teaching_advice 根据当前观察和已提交的 U2 会话状态，按 instance/learner/project/issue/policy 范围计算连续不同 Job 的同类观察。重复读取同一 Job、提示升级或同 Job 新会话不增加次数；未知旧状态或不同类别中断连续计数。revision 可随同一 issue 的学生修改变化，但证据自身始终按当前请求核验。

Job 的顺序采用该范围内工作流首次保存的位置；后续新会话重读旧 Job 不将它移到序列尾部。当前会话的新观察仅替换自身位置，新 Job 才追加。建议描述该 issue 已提交的最近连续观察，不因正在查看旧报告而重排历史。

第三次起返回 suggest_hint_request=true 和独立建议文案；不修改提示等级、卡片、模型输入、工具权限或模型预算。每个新 run 继续 L1，升级仍须独立 hint_next。既有会话/动作事务提交成功后才发布建议，重放不新增次数，重启继续读取已提交状态。

## 边界

不新增 U3 学习库，不保存画像或“掌握”判断，不调用 UA-10。不将工具任务成功计作错误，也不将 U2 的锁存器接收映射当成真实 detector。当前真实生产方尚不能提供合格错误诊断时，不会因中性综合报告触发建议。

字段属于 U2 私有扩展投影，不修改共享 DTO 或 GUI；旧状态缺少元数据时保守停止计数，不回填过去的错误事实。

## 验证

新增 7 项测试先复现功能缺失，再验证不同 Job 的三次建议、同 Job 去重、作用域隔离、反例/未知中断、可信条件与重启/动作重放。正式 Runtime + SQLite 场景验证第三次仍 L1、单张卡、0 模型调用，明确 hint_next 后才进入 L2。测试的 tool 标签来自合成契约输入，不作为真实检测证据。

独立审查另外复现了“j1 错误、j2 中断、j3/j4 错误”后重读 j1 被误计为第三次的问题，已按首次 Job 位置修复。新增 2 项回归验证重读后仍为 2 次、不建议，以及重读提交后的新 j5 正确为 3 次；两项先失败后通过，阶段 25 合计新增 9 项。复核不新增学习表或外部权限，也不将旧 Job 的新会话当新发生事件。
