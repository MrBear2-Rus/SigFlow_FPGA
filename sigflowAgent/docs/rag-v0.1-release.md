## 实施及验证

Parent–Child 来源分块、预算装配及引用白名单已接入 U2。收尾修复分离未驱动/多驱动、正常命令/解析/语法错误，修正模块实例化和数字字面量位宽映射；来源缺失和装配遗漏沿 Adapter→Provider→Evidence→RunState 传递。充分性保持 `answerability=not_assessed`。

2026-10-15 本地全套 132 项测试：116 通过、8 失败、2 错误、6 跳过。RAG/课程相关 72 项中 67 通过、5 个真实质量失败，无接口错误；新增概念及 U2 测试 9/9 通过，原课程/Child 测试 26/26 通过。

冻结旧76题中 67 道可回答题完整证据覆盖 41/67→43/67；新24题中 20 道可回答题为9/20。没有原 PASS 退化。精确告警码组 20/20 PASS；100题离线装配引用身份检查326/326、伪造引用拒绝100/100，工程证据保留及完整请求预算检查均通过。结果不等于真实模型回答准确率。

保留的五项质量失败涉及旧 Top3 官方/笔记排序、锁存器直接证据排名、数据竞争直接证据排名、开发题无匹配和诊断 Recall10 未达原1.0要求。另三项 Gateway 失败、两项错误与环回套接字 WinError10013 相符；六项真实 UCAgent 测试因依赖未配置跳过。没有通过放宽质量 gold 或删除失败来提高通过率。

## 使用与边界

在 `sigflowAgent` 目录运行：

```powershell
python -m sigflow_edu_agent --provider rule --once
python -m examples.rag_v01_u2
```

接口、输入输出及状态字段见 [U2 联调说明](rag-v0.1-u2-integration.md)。默认数据库路径根据源码位置确定；独立安装包可用 `SIGFLOW_COURSE_DB` 或 `--course-db` 指定本数据库。

中文自然语言召回、多事实选择和不可回答题拒答仍存在限制。来源覆盖与装配成功不代表回答充分；引用器只验证身份和原文定位，不判断语义蕴含。8192字节上下文、4096 UTF8字节上界token估计、16KiB请求保护保留。

按用户交付要求提交数据库。课程正文再分发许可尚未全部核实，来源使用范围与审阅状态应沿用数据库登记；提交不代表许可核查已完成。原始下载、旧库、审计备份、密钥及临时文件不进入提交。

构建测试与重建数据库需要额外原文数据和 PyYAML，不是运行预构建数据库的条件。完整原始审计、逐题输出和修复前备份留在开发机 audits 目录；本提交保留公开可读的结果摘要。
