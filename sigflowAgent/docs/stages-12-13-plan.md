# 阶段 12–13：重复模型评测与教师汇总

日期：2026-10-13。对应自研 UA-08，沿用本轮继续实现、不提交不推送的范围。

设计：evaluation/model.py 接受宿主提供的冻结 ModelCase，按每场景 3–10 次评测，
复用证据检查、模式门禁、checked_card 与 RuleProvider。每个候选最多修复一次，
全批限制模型调用次数。DeepSeek 模式必须实际 DeepSeekProvider，mock 模式独立标记。
机器报告只记录版本、输入摘要、输出摘要、计数和固定原因，不包含问题/证据/候选正文。
通过检查的最终卡片另存于返回对象的内存 review_samples，供可信宿主组织教师材料。
不自动导出全文，不调用 EDA；冻结集与 API 配置未提供时只运行替身测试。

evaluation/review.py 汇总两名匿名教师针对同一评测结果的四维 0–2 分。
每个 sample 必须由两名不同 reviewer 覆盖；重复、未知 sample、无效分数拒绝。
缺评审记 incomplete，平均低于 6/8 或任何未解决严重项均不能通过。
汇总保留分项与分歧，不验证教师资格或代替盲评流程，不使用模型评分。
相比扩展数据库/HTTP，此纯接口方案保持 U2 与 U1/U3 低耦合。
