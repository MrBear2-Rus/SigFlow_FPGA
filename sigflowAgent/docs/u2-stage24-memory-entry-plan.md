## 设计

现有 Runtime 已接受 TeachingMemoryPort，但正式 bootstrap/ready 启动流程尚未转发该参数。采用可选、仅限 Python 调用的关键字参数 `main(argv=None, *, teaching_memory=None)`，继续复用正式工厂、状态库、HTTP 和关闭流程。普通命令行默认保持未配置。

不增加动态模块导入、CLI 插件路径、bootstrap 配置字段或 HTTP 注入入口。相比另写启动器，该方式保留唯一的宿主初始化流程；相比直接依赖 U3 模块，该方式不引入未签收的依赖或方法约定。实际适配器由可信组合层提供，按阶段 23 的 U2 内部端口转换双方签收接口。
