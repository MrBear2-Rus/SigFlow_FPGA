# L4 参考解规格

L4 为主动查看经审阅的参考解。受控试点帮助已使用 L3 线索、仍需要校验自身推理的学生，阅读一个具体错误的机制、修正要点和验证方法。

| 需求 | 行为 |
| --- | --- |
| L4-R01 入口条件 | 当前有效运行处于 L3 `WaitingStudent`，没有待处理动作或活动验证计划，动作预算可用。试点开关、访问策略和匹配材料均通过时，界面允许申请查看。其他条件下明确显示不可用原因。 |
| L4-R02 两次操作 | 首次点击申请后只显示题目、修订和查看影响。挑战有效期 300 秒。第二次独立点击确认才签发、核销凭据。普通提问和下一提示保持原行为。 |
| L4-R03 材料范围 | 首版覆盖全加器 `cout` 遗漏 `cin` 一个案例。参考解绑定真实工程、修订、问题与材料摘要。开发夹具标记为合成，正式材料需两位不同审阅者的可核验记录、有效期与撤销状态。 |
| L4-R04 正文交付 | U2 确认凭据有效且核销成功后，专用接口可按当前状态读取只读正文。界面沿用现有 L4 位置和对话卡片区域，支持长正文滚动、选择与复制。 |
| L4-R05 失效与隔离 | 工程或修订变化、取消或运行切换时清除正文和确认界面。过期、未知、越权或已撤销的材料无法取得；已显示卡片随状态校验失效而关闭。正文无常规持久化、模型调用或工具执行。 |
| L4-R06 重试与恢复 | 重复请求按动作 ID 去重。核销结果不明时，同一实例恢复后核对原操作。新 Gateway 实例使用新运行和新授权。 |
| L4-R07 兼容与开放 | 首版默认关闭。普通教学接口保持 L1–L3 及旧版能力响应。通过试点验收后，可信启动配置才允许精确开放已登记的范围。 |

试点夹具基于 `examples/full_adder` 的隔离副本，将 `cout` 固定为 `a & b`。基线仿真在 `a=0, b=1, cin=1` 时应观察到 `cout=0`，算术预期为 `sum=0, cout=1`。修正后的验收使用全部 8 组输入。参考解只读呈现，学生负责修改工程与执行验证。首版范围限于固定审阅材料和本机可信 UI。

技术实现见[设计](design.md)和[接口契约](contract.md)。每项需求的实测证据按[验收矩阵](verification.md)记录。
