# L4 参考解验收和开放条件

当前状态为待执行。表内结果只定义验收方法，实施后以当前源码、原生运行和正式宿主产物记录结果。过往内部参考动作测试可作为基线，见[阶段 21](../../history/stages/stage-21-reference-host.md)及[阶段 30](../../history/stages/stage-30-reference-body.md)。

| 验收 | 操作 | 通过条件 |
| --- | --- | --- |
| L4-A01 真实仿真夹具 | 用隔离的全加器缺陷修订运行 Verilator。再验证包含修正的隔离修订。 | 缺陷修订在 `011` 的 `cout=0` 可复现，预期为 `1`。修正修订 8 组输入的 `sum` 和 `cout` 均正确。材料只匹配经登记的缺陷修订。 |
| L4-A02 两阶段门禁 | 对同一运行依次测试 L1、L2、L3。设置活动计划、待处理动作和预算耗尽。L3 合资格时点申请再点确认。 | 只有满足 [R01](spec.md) 的状态可申请。第一次只产生挑战，第二次发生一次签发和一次核销。确认后从专用入口读到匹配摘要的材料。 |
| L4-A03 通道和作用域 | 在默认配置调用专用端点，在试点配置伪造挑战或凭据，仅用普通 bearer、错误 learner、外部运行、无效 Origin 或重复头调用。 | 错误情形全部拒绝，未授权响应无挑战或正文，Gateway 核销次数为 0。默认配置仍可执行原教学请求。 |
| L4-A04 时效和版本 | 设置过期挑战、过期凭据、过期材料。确认前保存出新修订，在慢正文读取期间切换到新修订。 | 所有旧上下文均拒绝。重新读取当前运行，界面无旧挑战或正文。 |
| L4-A05 重放与恢复 | 双击确认，分别丢弃 Gateway 签发和核销响应。对同键同载荷重发，并尝试以另一动作或载荷重用凭据。在 Gateway 核销后、Runtime 确认前中止进程。重启同一实例的 sidecar，再重启整个 IDE。 | 签发结果不明确且客户端无凭据 ID 时不再次签发。挑战过期前保持等待。确认同键重放只返回元数据，异键或异载荷拒绝。原实例完成现有恢复并显式重核后可按新状态版本读取，核销事务只有一次。新实例须重新申请。 |
| L4-A06 撤销和数据隔离 | 分别在申请后、核销后、慢读取时及卡片已打开时撤销。检查常规状态、动作重放、事件、教学记忆、模型输入、常规数据库及日志。 | 后续投递拒绝，已打开卡片在参考状态复核失败后清除，迟到响应丢弃。普通数据中找不到测试正文、通道令牌或 receipt ID。从申请到阅读没有模型调用和新 EDA Job。私有凭据存储按既有授权审计规则保留。 |
| L4-A07 原生交互 | 从现有 L4 位置分别测试返回、再次申请、断线、关闭和切换运行。150% 缩放下检查浮窗及短窗口。 | 两次动作独立，错误原因可读，正文可滚动到底及选择复制，同一上下文中的返回和焦点行为符合现有工作台习惯。 |
| L4-A08 完整受控试点 | 使用真实 Gateway、正式宿主、原生工作台和标记为合成的材料，按 R01–R06 跑一次完整流程。 | 原生界面呈现当前题目和修订、只读正文及授权状态，全程证据可复查。结果登记为合成试点验收。 |
| L4-A09 兼容和关闭 | 对旧客户端和无配置启动分别运行 L1–L3 回归。在已显示卡片时关闭试点并重新启动 sidecar，尝试重放旧凭据。 | 普通教学信封及动作行为不变，原生滚动回归通过。关闭后无新签发，仍持有的凭据无法读取正文，界面清掉旧卡。 |
| L4-A10 正式材料 | 以可信审阅来源验证两位审阅者、绑定范围、摘要、有效期及撤销记录。跑一次正式原生交付，再撤销材料。 | 仅已登记工程和修订可进入流程。审阅证据与正文匹配，撤销后拒绝读取。 |

## 复测入口与结果登记

Windows 上从仓库根目录运行基础构建、正式宿主 HTTP 回归及原生控件测试。原生测试使用[默认交互桌面](../../guides/environment.md#原生-gui-回归)。L4 专用回归随 T02、T03 和 T04 加入，并把其确切命令与运行结果登记到本文件。

```powershell
$env:PYTHONPATH = "$PWD/agent/src;$PWD/sigflowAgent"
& .\sigflowAgent\.venv\Scripts\python.exe -m unittest discover -s agent/tests -t agent -p test_teaching_http.py -v
cmake -S . -B build-main-msvcrt -DSIGFLOW_BUILD_TESTS=ON -DSIGFLOW_BUILD_EDU_AGENT=ON -DSIGFLOW_BUILD_U2_INTEGRATION=ON -DSIGFLOW_BUILD_AGENT_GUI_TESTS=ON
cmake --build build-main-msvcrt --target edu_native_reading_smoke edu_u2_gateway --parallel 6
ctest --test-dir build-main-msvcrt --no-tests=error -R '^edu_native_reading_smoke$' --output-on-failure
```

每条结果登记验收编号、提交号、平台与缩放、数据来源、实际命令、结果（通过、失败、未执行）、证据位置和复核者。合成材料与真实审阅结果分别登记。截图使用合成材料或可公开范围，机器日志不记录参考正文和凭据。

## 试点开放和退回

合成联调以 L4-A01–A09 通过为阶段完成条件。正式试点还需要 L4-A10 通过和 U1、U2、S3 的联合签收。开启范围限制到已登记的工程、修订及题目。上线后观察申请、确认、拒绝、重核和撤销的元数据计数。

出现跨版本交付、重复核销、正文写入常规日志或无法复核撤销时，关闭可信启动配置并重启 sidecar。确认专用接口不可用、旧卡清空、L1–L3 继续可用。原核销审计留存以供排查。修复并重复适用验收后再开放。
