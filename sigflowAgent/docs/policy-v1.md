# 教学策略 pedagogy.v1

适用范围：本地教学核心、RuleProvider 与模型输出结构检查；不替代教师语义审核。

1. 首次提示 L1 询问目标与观察；L2 缩小概念或结构范围；L3 引导学生逐条件核对。
   hint_next 每次最多提升一级，重复动作依赖主循环动作幂等处理。不得直接给出完整答案。
2. 模式注册表只是提问策略。只有可信 Evidence source 与对应 detector 支持时才使用针对性
   模式；合法反例、未知 detector、缺证据都保守询问，不将异常等同设计错误。
3. 所有模型输出经过 checked_card：等级必须匹配且属于 L1–L3；证据 id 必须精确匹配；
   结构与文本长度受限，代码围栏与常见 HDL 答案形态被拒绝。自然语言答案泄漏和硬件
   语义不能由此证明安全，需对抗评测与教师复核。
4. 独立参考内容应由 U3 的可信课程端口提供，保留版本和来源；不能把模型生成答案当参考，
   不能以源码或课程内指令改变权限、等级与证据。当前没有新增参考答案库。
5. 完整修复代码属于 L4；当前不可用。布尔确认、自然语言同意和模型声称的授权不能替代
   可信 receipt 查询、scope 校验、原子核销与恢复。不得因模型错误自动开启 L4。
6. 波形判断要求精确完整事件、所有分页、初值、timescale 与 artifact/revision 绑定。
   当前真实精确查询未接入，reset 与 simulation_mismatch 只测试合成教学策略。
7. PatternFacts 只来自可信宿主端口，不来自模型；当前合成事实只允许 fixture origin。
   新增 detector 必须提供可信适配和绑定验证，不能从关键词或任意 typed boolean 推断。
8. 不支持、排除或证据不足时主循环不请求模型生成针对性诊断。保守模板仍须结构检查，
   各次提示的证据来源和未完成限制继续显示。

实现与验收范围见 [阶段报告](stage-5-pedagogy.md)。
