# U2 正式接入与交付实施计划

计划日期：2026-10-20；验收更新：2026-10-21。基线 04648a9，接续阶段 27。用户已批准完成 U2 接入适配、UA-10 对接准备、L4 业务收尾、评测和必要依赖。

**Goal:** 让正式宿主可明确加载并调用 U2 教学引擎，交付真实输入到位即可组合的学习、参考材料和评测组件。

**Architecture:** 组件全部位于 sigflowAgent；复用 Runtime/SQLite 的动作、幂等、审批和恢复。共享 API 仅投影已有契约可表示的卡片；等待态不伪装为完整教学终态。以 sigflow_u2 独立名称供正式宿主导入，避免和 U1 的 sigflow_edu_agent 同名。UA-10 通过可信调用和操作级连接工厂组合，L4 正文仅通过已核销且重新检查的可信内部端口读取。

**Tech Stack:** Python >=3.11 标准库、SQLite、unittest；现有 setuptools 仅用于离线构建验证。

## 约束与取舍

- 当前工作树保留既有未提交修改与 stash；不提交、不推送，不恢复或修改 demo。
- 不改 agent、Core、main、共享契约真源或 U3 存储；不新增平行 HTTP 服务。
- 采用 U2 组件供 U1 注册；整套服务替换会扩大职责，继续等待则无法完成 U2 侧接入，因此采用前者。
- 不制作教师身份或实际 UA-10 实现；契约接收端、审阅回调和评分仅用于明确标识的合成测试。
- 缺团队冻结数据不运行收费模型批次；现有 DeepSeek 显式入口保留，预检不读取密钥或调用网络。
- 所有测试临时目录放在工作区自有目录；只清理本次创建的临时文件。
