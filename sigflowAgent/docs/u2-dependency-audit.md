## 接口差异

既有 U2 独立宿主仍提供 `u2.host.v1`。阶段 32–34 已补齐正式 agent 服务的可选同进程组合，新增带明确 `u1.u2-teaching.v1` 标识的 `/api/v1/u2` 扩展，详见[接入说明](u1-u2-composition-guide.md)。原生 AgentApiClient 仍使用基础 sessions/runs 路由，没有消费新扩展；服务端接通不等于 GUI 已接通。本轮按授权修改 agent 中 U2 所需的接线，保留原基础语义和共享冻结 schema。

UA-10 实际接收端的 Python 参数和回执 DTO 仍需与 U3 冻结确认。U2 接入点和操作级适配以内部端口交接；不把自行生成的 SQLite 学习库、替代服务或模拟接收端当成 U3 已交付。画像、掌握程度、导出/删除、保留期均继续由 U3 负责。

## 支持声明修正

此前 support_matrix 将锁存器报告的接收映射记作 production_detector=true。源代码核查只发现规范化 smoke 中的诊断种子，未找到生产插件发出 EDU_LATCH_INFERRED；现拆分为 report_adapter_available=true、production_detector=false、producer_status=external_delivery_required。先失败回归已复现旧声明，修正后 6 项交接回归通过。

这不撤销已有真实综合任务观察：任务报告仍可证明指定工具在指定 revision/snapshot 上执行并生成了产物，但不能据此认定锁存器错误或设计正确。
