当前 U1 响应末端检查能够将新路径形式和已配置秘密拒绝为固定、通过契约校验的 503 错误信封。本地扩展保留这道检查，没有为 U2 放宽脱敏规则。

本次发现并修复的是组合测试的可移植性：

- 可选 U2 测试原先在模块导入阶段无条件导入 U2。现在先检查支持版本及可选包是否存在；缺 U2 或 Python <3.11 时明确跳过该组合模块，已安装包内部的其他导入错误继续暴露。隔离子进程覆盖三个模块与两种条件。版本信息模拟只验证分支，不代表已在真实 Python 3.9/3.10 上重新完成回归。
- 部分测试依赖以前运行生成的忽略目录作为 TemporaryDirectory 父目录，新检出时会失败。测试现自行初始化自己使用的工作区目录，不再依赖其他测试先运行；失败复现在独立临时子目录完成，没有删除或迁移历史日志。

另在完整回归中复现 POSIX 启动器因 core.autocrlf 转成 CRLF；现以 `agent/bin/.gitattributes` 的精确路径规则固定 LF，脚本字节与 HEAD 一致，执行模式和逻辑均保持。首次完整运行的两项失败及三项定向通过均保留。

运行时的状态机、证据摘要、审批配额、重放、L4 和取消边界没有因适配而放宽。实际修改范围和红绿记录见本计划工作区与[机器验证](verification-stage35.json)。
