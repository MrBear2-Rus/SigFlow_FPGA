# SigFlow理念

**SigFlow** 是一款面向逻辑电路设计的集成开发平台。基于自研算法，SigFlow首次实现了以**Verilog代码和电路图的双向实时同步开发范式**为核心的电路设计平台，并基于该平台，构建插件化、可扩展的工具生态，对开源 EDA 工具进行重构式的有机融合，深度释放其交互潜能。

产品名称为**SigFlow**，意涵 *Signal Flow* 与 *Workflow*。既指代逻辑电路中信号的传播结构，也体现以工作流驱动设计流程的理念，同时隐喻打破 Verilog 与逻辑电路图之间信息流动壁垒的创新范式

目标用户：开源EDA生态用户，电子专业学生，FPGA开发者，数字IC架构师

# 技术创新一：自研SigFlow方法，实现**图形与代码双向可逆编辑**

## SFTree构成

1. SFTree不是一个普通的AST，而是一个Verilog 结构语义树。SFTree收集四层节点
    1. Project Node：核心内容是项目路径
    2. File Node：核心内容是文件路径
    3. Module Node：核心内容是模块接口以及接口的连接情况
    4. Structural Block Node：核心内容是模块接口以及接口的连接情况，以及接口的计算关系
    5. Submodule Node：子模块，核心内容是模块接口以及接口的连接情况
2. SFTree结构化了Assign等行为级操作语句，我们将任何行为级操作语句/语块视为一个结构，并分析结构的输入输出，再让语句本身描述其计算关系，这样就实现了模块实例、门原语以及任何操作性语句之间的结构级等价。很显然，这套逻辑是面向画布绘制的，画布绘制又是最面向直觉，因此，这套逻辑是面向直觉的，具有非常好的同构性和正交性。
3. SFTree还维护了模块定义表，模块实例表，信号表等符号表，用于IDE分析和局部跳转

## SFTree相关操作

1. 全量解析Verilog文件，生成SFTree
2. 增量解析Verilog文件/文段，更新SFTree
3. 电路图全量解析，生产SFTree
4. 电路图增量解析，更新SFTree
5. SFNode插入、删除、注册操作
6. SFNode内部信息修改
7. 符号表全量重建
